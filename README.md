# Strategy Game Space

Космическая 4X с развитой экономикой, взаимозависимыми планетами, наземными операциями и осадами. Проектируется собственный движок с текстовыми данными, управлением из CLI и запуском симуляции без графики для разработки через ИИ агентов.

**Текущий этап: проработка спецификации. Версия документации 0.1, DRAFT от 2 ноября 2026 года.** Реализация игры и движка ещё не начата. Язык, графическая библиотека, формат времени и масштаб наземного боя не зафиксированы.

## Основные идеи

- Специализированные планеты дают высокий профильный выпуск, требуют содержания и зависят от поставок.
- Планеты с разнообразным производством устойчивее к изоляции, уступая в эффективности отдельных отраслей.
- Торговля и снабжение связывают экономику с космической и наземной войной.
- Осмысленная осада учитывает запасы, инфраструктуру, снабжение обеих сторон и ценность захваченной территории.

## Как продолжать

Начать с основ проекта и реестра решений. Следующий шаг — выбрать формат времени, визуальное представление и масштаб наземных боёв. После этого последовательно уточнять экономику, войну и технический контракт, переводя отдельные модули из DRAFT в READY.

Новые решения отражаются в профильном документе и реестре. Все проектные записи хранятся здесь. Правила работы агентов приведены в [AGENTS.md](AGENTS.md).
